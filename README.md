# Personal Homelab

My repo for my homelab setup, where I self-host services such as Home Assistant and experiment in my lab environment for learning and for fun.

More info and my docs about my homelab hardware, networking, IaC setup/deployment, self-hosted services are in [docs](./docs/) and published to [jyyhomelab.com](https://jyyhomelab.com) with [Zensical](https://zensical.org/).

## Dev Setup

I use my dev NixOS machine for writing and deploying automations (IaC, scripts, etc).
See [Local Dev Setup](./docs/guides/local-dev-setup.md) for the dev environment,
first-time setup and helper commands.
